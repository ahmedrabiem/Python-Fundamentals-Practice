## 🚀 Getting Started

### Prerequisites

- Python 3
- Jupyter Notebook or JupyterLab

### Run the Notebooks

1. Clone or download this repository.
2. Open the project folder.
3. Start Jupyter Notebook or JupyterLab.
4. Open a notebook (`.ipynb`) and run the cells.

You can also open and run the Python scripts (`.py`) using a Python interpreter.
